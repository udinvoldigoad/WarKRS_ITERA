Buka browser dan login

Login menggunakan akun SIAKAD di browser WAR KRS. Sesi tersimpan di profil khusus dan tidak mengganggu browser sehari-hari.

  2. Selesaikan login dan verifikasi manusia di SIAKAD.
  3. Klik Periksa login untuk melanjutkan.

Password dimasukkan langsung di SIAKAD. Pengaturan verifikasi tersedia di Settings.
